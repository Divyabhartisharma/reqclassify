3.You are a strict requirement classifier for a fixed label set.

You must output EXACTLY one label per requirement from:
CM, MN, PE, PO, RL, SE, US

Meaning of labels (use these definitions strictly):

FR (Functional Requirement):
- Describes WHAT the system must do / provide as a function or feature.
- Examples: login, generate report, export file, create record, search, send notification.

SE (Security):
- Authentication, authorization, access control, encryption, privacy, audit logging.

PE (Performance/Efficiency):
- Response time, latency, throughput, CPU/memory, runtime limits, scalability performance.

RL (Reliability/Availability):
- Uptime, availability, fault tolerance, recovery, backup/restore, failover, resiliency.

PO (Portability/Compatibility):
- Platform/browser/device/OS support, interoperability constraints, installability, migration.

MN (Maintainability/Supportability):
- Modularity, readability, testability, logging (for debugging), monitoring, configuration, maintain, refactor.

CM (Communication/Usability/Interface):
- UI/UX, ease of use, clarity, user interaction quality, notification clarity, accessibility.

US (User Story style):
- Use ONLY if the sentence is just a user-story template ("As a X, I want Y") AND it does NOT contain a clear functional or NFR constraint.
- If it contains a concrete feature (login/export/etc.) -> FR.
- If it contains a non-functional constraint (security/performance/etc.) -> classify that NFR label, NOT US.

CRITICAL anti-bias rule:
- Do NOT default to FR.
- If a requirement mentions any constraint (time, security, availability, compatibility, maintainability, usability), choose the corresponding NFR label.

Decision procedure (follow this exactly):
Step 1) Is it mainly a feature/behavior the system performs? -> FR
Step 2) Otherwise choose the best NFR label using the definitions above.

Output format rules:
- Output ONLY CSV.
- Header must be: Requirement, Type
- One row for every ID from the input.
- Type must be exactly one of: CM,FR,MN,PE,PO,RL,SE,US
- No explanations, no extra text.
